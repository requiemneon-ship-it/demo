# Interactive business demos

A small collection of self-contained browser demos for typical small-business workflows.  
Набор интерактивных демо для типовых задач малого бизнеса.

## Included demos

| File | Demonstrates |
| --- | --- |
| [`zapis.html`](https://requiemneon-ship-it.github.io/demo/zapis.html) | Appointment flow with occupied-slot handling and an owner view |
| [`kalkulyator.html`](https://requiemneon-ship-it.github.io/demo/kalkulyator.html) | Price calculator with configurable options and lead form |
| [`sait-vizitka.html`](https://requiemneon-ship-it.github.io/demo/sait-vizitka.html) | Responsive service-business landing page with prices and booking form |
| [`menu.html`](https://requiemneon-ship-it.github.io/demo/menu.html) | Searchable QR menu with cart and order summary |

These are front-end demonstrations with sample names, prices and data. They do not claim live payment, CRM or Telegram delivery. Production versions require connection to the client's backend or chosen service.

## Run locally

No build step or dependencies are required:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Commercial use

The layouts and flows can be adapted to a real business after the scope, data source, delivery channel and acceptance criteria are agreed.
